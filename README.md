## ✨ Professional Web Developer Portfolio

A modern, responsive, and visually stunning portfolio website showcasing my passion for web development and cyber security.

### 🎯 Features

- **🌟 Hero Section** - Eye-catching animated hero with particles.js background
- **⌨️ Typing Effect** - Dynamic typing animation showcasing multiple roles
- **🎨 Modern Design** - Beautiful gradient themes with smooth animations
- **🌓 Dark Mode** - Seamless light/dark theme toggle
- **📱 Fully Responsive** - Perfect display on all devices
- **🎯 Skills Showcase** - Animated progress bars displaying technical skills
- **💼 Portfolio Gallery** - Beautiful project cards with hover effects
- **📅 Timeline** - Interactive education and experience timeline
- **✉️ Contact Form** - Integrated contact form
- **🔥 Smooth Animations** - Scroll-triggered animations and transitions

### 🛠️ Technologies Used

- HTML5, CSS3, JavaScript (ES6+)
- Bootstrap 5, Font Awesome, Particles.js, Ionicons

### 🚀 Quick Start

1. Clone the repository
2. Open `index.html` in your browser
3. That's it! No build process required.
